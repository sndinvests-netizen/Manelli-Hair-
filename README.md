# Manelli Hair

Marketing strategy, content, and brand assets for **Manelli Hair** — a luxury hair extension brand.

## Folder Structure

```
manelli-hair/
├── brand/          # Brand identity, colors, positioning
├── content/        # Content calendar, captions, scripts
├── email/          # Klaviyo email flows
├── ads/            # Paid ad copy (Facebook, Instagram, TikTok)
├── blog/           # Blog post outlines and drafts
└── assets/         # Images, logos, media (add manually)
```

## Brand Overview

- **Product:** Luxe Hybrid Weft Hair Extensions
- **Price:** $310 (16") / $425 (20")
- **Aesthetic:** Minimalist luxury — deep green, muted gold, cream
- **Audience:** Ambitious, luxury-minded women 25–45
- **Tagline:** *You're not buying hair. You're buying the character.*
